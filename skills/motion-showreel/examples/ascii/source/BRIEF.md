# 글자판 termpan (가상 프로젝트)

> 이 예제를 위해 지어낸 도구입니다. 도구, 명령, 수치 모두 가상입니다.

**글자판(termpan)**은 터미널 안에서 서버 상태를 보여 주는 대시보드입니다. 그래프도, 표도, 로고도 전부 글자로
그립니다. 설치는 명령 한 줄이면 됩니다.

- 실행: `termpan`
- 설치: `brew install termpan` (가상)
- 보여 주는 것: CPU, 메모리, 네트워크, 프로세스

핵심 문구: **글자가 모이면 그림이 돼요.**

톤: 똑똑하고 장난스럽고 담백합니다. 커서가 깜박이고, 흩어진 글자들이 날아와 도넛 모양을 이루고 빙글빙글
돕니다. 이어서 상자와 그래프가 글자로 채워진 대시보드가 켜집니다.
색: 어두운 남색 터미널, 연보라·하늘·연두·노랑·분홍 글자 (도쿄 나이트 계열).
소리: 칩튠, 128 BPM, 타자 소리와 삑 소리.
