# 폴드원 E1 (가상 프로젝트)

> 이 예제를 위해 지어낸 제품입니다. 회사, 제품, 치수, 성능 모두 가상입니다.

**폴드원 E1**은 3초면 접히는 20인치 접이식 전기자전거입니다. 이번 공개의 핵심은 접는 방식입니다. 프레임 가운데
경첩 하나로 앞쪽 절반이 옆으로 돌아 뒷바퀴 옆에 붙고, 핸들 기둥이 접히고, 안장이 내려갑니다.

| 항목 | 값 (가상) |
|---|---|
| 전장 | 1,520 mm |
| 휠베이스 | 1,050 mm |
| 바퀴 | 20인치 |
| 무게 | 16.4 kg |
| 모터 | 허브 모터 250W |
| 배터리 | 36V 10Ah, 최대 60km |
| 접은 크기 | 78 × 66 × 38 cm |

핵심 문구: **3초면 접혀요.**

톤: 정밀하고 믿음직하고 깔끔합니다. 파란 설계도 위에 흰 선이 그려지고, 치수선이 붙고, 부품이 분해되고, 접힙니다.
색: 청사진 파랑, 흰 선, 주석은 하늘색, 강조 한 군데만 노랑.
소리: 담백한 시네마틱, 선이 그어지는 소리와 경첩이 맞물리는 소리.
